# Inventra - Sistem Informasi Persediaan Barang Dagang

Inventra adalah prototype project mata kuliah Interaksi Manusia dan Komputer (IMK) berupa sistem informasi persediaan barang dagang berbasis web.

## Fitur

- Login demo
- Dashboard persediaan
- Data barang CRUD
- Barang masuk
- Barang keluar dengan validasi stok
- Simulasi barcode menggunakan kode barang
- Rekomendasi restock
- Laporan persediaan
- UI modern dan responsif

## Teknologi

- React.js
- Vite
- JavaScript
- CSS custom
- Recharts
- Lucide React

## Cara Menjalankan

1. Buka folder project di Visual Studio Code.
2. Jalankan perintah:

```bash
npm install
npm run dev
```

3. Buka alamat yang muncul di terminal, biasanya:

```bash
http://localhost:5173
```

## Catatan IMK

Prototype ini menerapkan prinsip IMK seperti visibility of system status, consistency, error prevention, recognition rather than recall, feedback, dan desain minimalis.
